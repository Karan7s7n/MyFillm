🎬 MyFilm – Movie Discovery Web Application (React + TypeScript)

MyFilm is a frontend web application built using React, TypeScript, and Vite, integrated with the TMDB REST API.
The application allows users to search movies, browse trending content, and view detailed movie information in a fast, responsive UI.

This project demonstrates real-world frontend development skills, API integration, clean architecture, and modern tooling used in production React applications.

🚀 Key Features

Movie search functionality using external REST API

Browse Now Playing, Popular, and Top Rated movies

Detailed movie pages (overview, rating, release date, runtime)

Genre-based movie filtering

Responsive UI for mobile and desktop devices

Optimized API service layer

Environment variable configuration for API security

Error handling for API failures

Scalable and maintainable component structure

📁 Project Architecture
src/
├── components/        # Reusable UI components
├── pages/             # Route-based pages
├── lib/               # API services (TMDB service)
├── hooks/             # Custom React hooks
├── styles/            # Global styles
├── App.tsx            # App entry
└── main.tsx           # Vite bootstrap


This structure follows industry-standard React best practices for scalability and maintainability.


API keys are not hardcoded and are excluded from version control.
